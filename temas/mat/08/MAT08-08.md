## PT

### Explicação

#### O que é uma fração algébrica

Uma fração algébrica é uma divisão em que o numerador e o denominador são expressões algébricas.
São frações algébricas:

5/(x - 3), (x^{2} - 9)/(x + 3), (2x + 1)/(x^{2} + x)

A fração numérica que você já conhece segue exatamente as mesmas regras. A diferença é que agora o
denominador contém letras, e por isso ele pode valer zero para alguns valores. É daí que nasce a
primeira pergunta a fazer sempre.

#### Antes de tudo: para que valores a fração existe

Divisão por zero não tem resultado. Então, antes de simplificar ou operar, descubra quais valores
tornam o denominador zero e exclua esses valores.

Em 5/(x - 3), o denominador zera quando x = 3. A fração existe para todo x ≠ 3.

Em (2x + 1)/(x^{2} + x), fatore o denominador: x(x + 1). Ele zera quando x = 0 e quando x = -1. A
fração existe para todo x fora desses dois valores.

Essa condição não é detalhe burocrático. Ela é a razão de muitas respostas de prova virem com a
observação "com x diferente de tal valor".

#### Simplificar é cancelar fator, nunca parcela

Numa fração numérica você simplifica dividindo numerador e denominador pelo mesmo número. Numa
fração algébrica você divide os dois pelo mesmo **fator**. E fator é o que está multiplicando a
expressão inteira, não um pedaço que está somando.

Por isso o primeiro movimento é sempre **fatorar em cima e embaixo**. Sem fatoração não existe
simplificação legítima.

**Exemplo 1.** Simplificar (x^{2} - 9)/(x + 3).
O numerador é uma diferença de quadrados: (x - 3)(x + 3). A fração vira
[(x - 3)(x + 3)]/(x + 3). O fator (x + 3) aparece nos dois lugares e pode ser cancelado. Sobra
x - 3, válido para todo x ≠ -3.

**Exemplo 2.** Simplificar (x^{2} - 4)/(x^{2} + 4x + 4).
Em cima, diferença de quadrados: (x - 2)(x + 2). Embaixo, trinômio quadrado perfeito:
(x + 2)^{2}. Cancelando um fator (x + 2), fica (x - 2)/(x + 2), válido para x ≠ -2.

#### Multiplicar e dividir

Multiplicar é multiplicar numerador com numerador e denominador com denominador, mas o caminho
esperto é fatorar tudo antes e cancelar os fatores repetidos. Dividir é multiplicar pelo inverso da
segunda fração.

**Exemplo 3.** Calcular (x + 1)/(x - 2) · (x^{2} - 4)/(x^{2} - 1).
Fatorando: (x + 1)/(x - 2) · [(x - 2)(x + 2)]/[(x - 1)(x + 1)].
Cancelam o fator (x + 1) e o fator (x - 2). Sobra (x + 2)/(x - 1).

#### Somar e subtrair

Aqui vale a mesma regra das frações numéricas: só se somam frações com o mesmo denominador. Encontre
o mínimo múltiplo comum dos denominadores, escreva as duas frações com ele e some os numeradores.

**Exemplo 4.** Calcular 1/x + 1/(x + 1).
O denominador comum é x(x + 1). A primeira fração vira (x + 1)/[x(x + 1)] e a segunda
vira x/[x(x + 1)]. Somando os numeradores: (2x + 1)/[x(x + 1)].

Quando os denominadores já vêm fatorados, o mínimo múltiplo comum é o produto dos fatores distintos,
cada um com o maior expoente que aparece. Por isso fatorar continua sendo o primeiro passo.

#### Erros comuns

**Cortar parcela em vez de fator.** Em (x + 3)/3 não dá para cancelar o 3, porque em cima
ele está somando. Só se cancela o que multiplica a expressão inteira.

**Simplificar antes de fatorar.** Olhar para (x^{2} - 9)/(x + 3) e cancelar o
9 com o 3 é o erro clássico. Fatore primeiro, sempre.

**Esquecer a condição de existência.** A resposta de uma simplificação carrega a restrição do
denominador original.

**Somar denominadores.** 1/3 + 1/4 não é 2/7, e 1/x + 1/y não é 2/(x + y).

**Esquecer de inverter na divisão.** Dividir por uma fração é multiplicar pelo inverso dela, e o
inverso troca numerador com denominador.

## EN

### Explanation

#### What an algebraic fraction is

An algebraic fraction is a division in which the numerator and the denominator are algebraic
expressions. These are algebraic fractions:

5/(x - 3), (x^{2} - 9)/(x + 3), (2x + 1)/(x^{2} + x)

The numerical fractions you already know follow exactly the same rules. The difference is that the
denominator now contains letters, so it may equal zero for some values. That is where the first
question to ask always comes from.

#### First of all: for which values does the fraction exist

Division by zero has no result. So, before simplifying or operating, find out which values make the
denominator zero and rule those values out.

In 5/(x - 3), the denominator is zero when x = 3. The fraction exists for every x ≠ 3.

In (2x + 1)/(x^{2} + x), factor the denominator: x(x + 1). It is zero when x = 0 and when x = -1.
The fraction exists for every x outside those two values.

This condition is no bureaucratic detail. It is the reason so many test answers come with the note
"with x different from such and such a value".

#### Simplifying means cancelling a factor, never a term

In a numerical fraction you simplify by dividing numerator and denominator by the same number. In an
algebraic fraction you divide both by the same **factor**. And a factor is what multiplies the whole
expression, not a piece that is being added.

That is why the first move is always to **factor top and bottom**. Without factoring there is no
legitimate simplification.

**Example 1.** Simplify (x^{2} - 9)/(x + 3).
The numerator is a difference of squares: (x - 3)(x + 3). The fraction becomes
[(x - 3)(x + 3)]/(x + 3). The factor (x + 3) shows up in both places and can be
cancelled. What is left is x - 3, valid for every x ≠ -3.

**Example 2.** Simplify (x^{2} - 4)/(x^{2} + 4x + 4).
On top, a difference of squares: (x - 2)(x + 2). Underneath, a perfect square trinomial:
(x + 2)^{2}. Cancelling one factor (x + 2) leaves (x - 2)/(x + 2), valid for x ≠ -2.

#### Multiplying and dividing

Multiplying means numerator times numerator and denominator times denominator, but the clever route
is to factor everything first and cancel the repeated factors. Dividing means multiplying by the
reciprocal of the second fraction.

**Example 3.** Work out (x + 1)/(x - 2) · (x^{2} - 4)/(x^{2} - 1).
Factoring: (x + 1)/(x - 2) · [(x - 2)(x + 2)]/[(x - 1)(x + 1)].
The factor (x + 1) and the factor (x - 2) cancel. What is left is (x + 2)/(x - 1).

#### Adding and subtracting

The same rule as with numerical fractions applies here: only fractions with the same denominator can
be added. Find the least common multiple of the denominators, rewrite both fractions with it, and
add the numerators.

**Example 4.** Work out 1/x + 1/(x + 1).
The common denominator is x(x + 1). The first fraction becomes (x + 1)/[x(x + 1)] and
the second becomes x/[x(x + 1)]. Adding the numerators: (2x + 1)/[x(x + 1)].

When the denominators already come factored, the least common multiple is the product of the
distinct factors, each with the highest exponent that appears. That is why factoring is still the
first step.

#### Common mistakes

**Cancelling a term instead of a factor.** In (x + 3)/3 you cannot cancel the 3, because on
top it is being added. Only what multiplies the whole expression may be cancelled.

**Simplifying before factoring.** Looking at (x^{2} - 9)/(x + 3) and cancelling the
9 against the 3 is the classic mistake. Factor first, always.

**Forgetting the existence condition.** The answer to a simplification carries the restriction of
the original denominator.

**Adding denominators.** 1/3 + 1/4 is not 2/7, and 1/x + 1/y is not 2/(x + y).

**Forgetting to flip in a division.** Dividing by a fraction means multiplying by its reciprocal,
and the reciprocal swaps numerator and denominator.
