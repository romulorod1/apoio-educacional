## PT

### Explicação

#### Uma regra que transforma entrada em saída

Pense numa máquina de vender bilhete de metrô. Você diz quantos bilhetes quer, e ela diz quanto
custa. Para cada quantidade que você informa, sai um preço, e sai um só. Não existe a situação em
que você pede três bilhetes e a máquina responde dois preços diferentes.

Isso é uma **função**: uma regra que associa cada valor de entrada a **um único** valor de saída. A
palavra importante é única. Uma regra que devolve duas respostas para a mesma entrada não é função.

O conjunto dos valores que podem entrar se chama **domínio**. O conjunto dos valores que saem se
chama **imagem**.

#### A notação

Escrevemos f(x) para dizer "o valor que a função f devolve quando a entrada é x". Assim, se

f(x) = 3x - 5

então f(4) é o resultado de trocar x por 4 em toda a expressão.

**Exemplo 1.** Calcular f(4) para f(x) = 3x - 5.
Substituindo: 3 × 4 = 12, e 12 - 5 = 7. Portanto f(4) = 7.

Cuidado com a leitura de f(4): isso não é f multiplicado por 4. É o nome da saída correspondente à
entrada 4.

#### O caminho de volta

Perguntar f(4) é ir da entrada para a saída. O caminho inverso também é útil: dada a saída, qual era
a entrada? Aí você resolve uma equação.

**Exemplo 2.** Para f(x) = 2x + 1, qual valor de x faz f(x) valer 13?
Resolvemos 2x + 1 = 13, o que dá 2x = 12 e x = 6.

Quando a saída pedida é zero, o valor de x correspondente tem nome próprio: é a **raiz** da função,
ou o zero da função. No gráfico, é o ponto em que a curva cruza o eixo horizontal.

#### Três formas de mostrar a mesma função

A mesma função pode aparecer de três jeitos, e saber passar de um para o outro é metade do trabalho:

**Por fórmula.** f(x) = 3x - 5 diz tudo em uma linha.

**Por tabela.** Escolhem-se alguns valores de x e calculam-se as saídas. Para a fórmula acima,
x = 0 dá -5, x = 1 dá -2, x = 2 dá 1, e x = 3 dá 4.

**Por gráfico.** Cada par de entrada e saída vira um ponto no plano cartesiano, com a entrada no
eixo horizontal e a saída no eixo vertical.

#### A função afim e o que o gráfico conta

Quando a fórmula tem a forma f(x) = ax + b, a função se chama **afim** e o gráfico é sempre
uma reta. Os dois coeficientes têm leitura direta:

- **b é onde a reta corta o eixo vertical**, porque f(0) = b. É o valor inicial, o que já
  existe antes de qualquer variação.
- **a é a taxa de variação**, o quanto a saída muda quando a entrada aumenta em uma unidade. Se a é
  positivo, a reta sobe. Se a é negativo, a reta desce. Se a é zero, a reta é horizontal e a função
  é constante.

**Exemplo 3.** Uma reta corta o eixo vertical em 4 e desce 2 unidades a cada unidade que se avança
na horizontal. Qual é a fórmula e onde ela corta o eixo horizontal?
O valor inicial é 4 e a taxa é -2, então f(x) = -2x + 4. Para achar onde corta o eixo horizontal,
resolvemos -2x + 4 = 0, o que dá x = 2.

**Exemplo 4.** Uma corrida de táxi custa 5 reais fixos mais 2,50 reais por quilômetro rodado. Quanto
custa uma corrida de 8 quilômetros?
A função é f(x) = 5 + 2,50x. Para 8 quilômetros: 2,50 × 8 = 20, e 20 + 5 = 25 reais.

#### Como reconhecer, no gráfico, que não é função

Se existir uma reta vertical que corte o desenho em dois pontos, aquele desenho não representa
função, porque haveria uma entrada com duas saídas. É o caso da circunferência e da parábola
deitada.

#### Erros comuns

**Ler f(x) como multiplicação.** f(3) não é f · 3.

**Confundir a pergunta.** "Calcule f(2)" e "para qual x vale f(x) = 2" são perguntas
diferentes, e uma delas pede resolver equação.

**Trocar os eixos.** A entrada vai no eixo horizontal e a saída no vertical. Trocar isso muda o
gráfico completamente.

**Achar que toda relação é função.** Se a mesma entrada admite duas saídas, não é função.

**Esquecer o valor inicial nos problemas de preço.** Uma conta de 30 reais fixos mais o consumo não
começa em zero, e a reta correspondente não passa pela origem.

## EN

### Explanation

#### A rule that turns an input into an output

Think of a metro ticket machine. You tell it how many tickets you want, and it tells you the price.
For every quantity you enter, one price comes out, and only one. There is no situation in which you
ask for three tickets and the machine gives two different prices.

That is a **function**: a rule that links each input value to **exactly one** output value. The key
word is exactly one. A rule that returns two answers for the same input is not a function.

The set of values that may go in is called the **domain**. The set of values that come out is called
the **range**.

#### The notation

We write f(x) to mean "the value the function f returns when the input is x". So if

f(x) = 3x - 5

then f(4) is the result of replacing x by 4 throughout the expression.

**Example 1.** Find f(4) for f(x) = 3x - 5.
Substituting: 3 × 4 = 12, and 12 - 5 = 7. So f(4) = 7.

Be careful how you read f(4): it is not f multiplied by 4. It is the name of the output that
corresponds to the input 4.

#### The way back

Asking for f(4) means going from input to output. The reverse trip is useful too: given the output,
what was the input? That is when you solve an equation.

**Example 2.** For f(x) = 2x + 1, which value of x makes f(x) equal 13?
We solve 2x + 1 = 13, which gives 2x = 12 and x = 6.

When the output asked for is zero, the matching value of x has its own name: it is the **root** of
the function, or the zero of the function. On the graph, it is the point where the curve crosses the
horizontal axis.

#### Three ways of showing the same function

The same function can appear in three guises, and moving between them is half the work:

**By formula.** f(x) = 3x - 5 says everything in one line.

**By table.** You pick a few values of x and work out the outputs. For the formula above,
x = 0 gives -5, x = 1 gives -2, x = 2 gives 1, and x = 3 gives 4.

**By graph.** Each input and output pair becomes a point on the coordinate plane, with the input on
the horizontal axis and the output on the vertical axis.

#### The linear function and what the graph tells you

When the formula has the form f(x) = ax + b, the function is called **linear** and the graph
is always a straight line. Both coefficients can be read directly:

- **b is where the line crosses the vertical axis**, because f(0) = b. It is the starting
  value, what is already there before any change happens.
- **a is the rate of change**, how much the output moves when the input goes up by one unit. If a is
  positive, the line rises. If a is negative, the line falls. If a is zero, the line is horizontal
  and the function is constant.

**Example 3.** A line crosses the vertical axis at 4 and drops 2 units for every unit it moves along
the horizontal. What is its formula, and where does it cross the horizontal axis?
The starting value is 4 and the rate is -2, so f(x) = -2x + 4. To find where it crosses the
horizontal axis, we solve -2x + 4 = 0, which gives x = 2.

**Example 4.** A taxi ride costs 5 reais as a fixed fee plus 2.50 reais per kilometre travelled. How
much does an 8 kilometre ride cost?
The function is f(x) = 5 + 2.50x. For 8 kilometres: 2.50 × 8 = 20, and 20 + 5 = 25 reais.

#### How to spot, on a graph, that it is not a function

If there is a vertical line that cuts the drawing at two points, that drawing does not represent a
function, because one input would have two outputs. That is the case for a circle and for a
sideways parabola.

#### Common mistakes

**Reading f(x) as a multiplication.** f(3) is not f · 3.

**Confusing the question.** "Find f(2)" and "for which x does f(x) = 2" are different questions,
and one of them calls for solving an equation.

**Swapping the axes.** The input goes on the horizontal axis and the output on the vertical one.
Swapping them changes the graph completely.

**Assuming every relation is a function.** If the same input allows two outputs, it is not a
function.

**Forgetting the starting value in price problems.** A bill of 30 reais fixed plus usage does not
start at zero, and the matching line does not pass through the origin.
